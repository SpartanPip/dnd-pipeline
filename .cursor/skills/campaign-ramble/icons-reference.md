# Map icon reference

Keys for `mapCellSchema.icon`, defined in `src/lib/icons.ts` (backed by
`react-icons/gi`, the Game Icons set). Pick the closest match; only add a
new entry to `MAP_ICONS` if nothing here fits.

| Key          | Use for                                      |
| ------------ | --------------------------------------------- |
| `castle`     | Castles, keeps, fortresses                   |
| `village`    | Villages, small towns                        |
| `tree`       | Notable single tree / grove marker           |
| `forest`     | Forests, woods                               |
| `mountain`   | Mountains, mountain passes                   |
| `cave`       | Caves, caverns, underdark entrances           |
| `dragon`     | Dragon lairs, dragon encounters              |
| `battle`     | Battlefields, warzones, duel sites            |
| `ruins`      | Ancient ruins, abandoned structures           |
| `waterfall`  | Waterfalls, notable water features            |
| `island`     | Islands                                      |
| `graveyard`  | Graveyards, tombs, crypts                     |
| `tower`      | Towers, bridges, lighthouses                  |
| `wizard`     | Wizard towers, arcane academies, spellcasters |
| `portal`     | Portals, teleportation circles, planar rifts  |
| `camp`       | Campsites, waystations                        |
| `port`       | Ports, harbors, docks                         |
| `throne`     | Capitals, thrones, seats of power             |
| `lair`       | Monster lairs (non-dragon), spider dens       |
| `duel`       | Arenas, dueling grounds                       |
| `temple`     | Temples, churches, shrines                    |
| `farmland`   | Farms, rural settlements                      |
| `volcano`    | Volcanoes, volcanic regions                   |
| `desert`     | Deserts, wastelands                           |
| `frost`      | Frozen/arctic regions                         |
| `landmark`   | Generic point of interest (default fallback) |
| `settlement` | Small hidden/hobbit-hole style settlements    |
| `mine`       | Mines, quarries                              |
